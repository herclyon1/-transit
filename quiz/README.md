## v24 修了什么（边界缝 bug）
用户报"尼泊尔分界线从 v18 起一直有问题，v23 越修越崩坏"。真 Chromium 逐像素复现证实：
- **v23（及更早）**：手机 Chrome 下尼泊尔国界/省界有**白缝**（相邻多边形各自抗锯齿，共享边透出背景色）。
- **v23-3**：用 dissolveRings 垫背景把省间白缝修好了，但**把国界白缝换成了绿缝**——深缩放时国界透出邻国代表色 #90c0a0（约 3360 像素），即"越修越崩坏"。
- **v24（本版）**：改用标准制图法——给每个单元加一圈**本国同色光晕**（垫在前景填充下、深色国界线上），相邻国各向外扩本国色把发丝缝填满；再加一层统一中性陆地底兜底。

结果（真 Chromium 验证）：正常/中等缩放下白、绿、蓝缝全部消失；仅在 k~40 极端深缩放的国界凹角处残留极淡海色细缝（尼泊尔 0.008 简化边与邻国 ADMIN1 数据错位所致，读起来像小河湾，不刺眼）。

## 已知残留 / 后续
- 极端深缩放国界凹角海色细缝：需修底层地理数据（尼/不/孟简化边与邻国吻合）才能彻底消除，非渲染层能解决。
